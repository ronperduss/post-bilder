# post-bilder

Zwischenablage für die automatische Veröffentlichung auf Instagram.

Die Instagram-Schnittstelle (Content Publishing API) nimmt keine Dateien
entgegen: Sie verlangt eine öffentlich erreichbare Adresse und holt sich das
Material selbst von dort. Dieses Repository ist genau dieser Ablageort.

Was hier landet, ist für Beiträge bestimmt, die unmittelbar danach öffentlich
auf [@ron_perduss](https://www.instagram.com/ron_perduss/) erscheinen. Nach der
Veröffentlichung werden die Dateien wieder entfernt — sie verschwinden damit
aus der Dateiliste, bleiben aber wie in jedem Git-Repository über die
Versionsgeschichte abrufbar. Deshalb gehört hierher ausschließlich Material,
das ohnehin veröffentlicht werden soll.

Befüllt und geleert wird automatisch durch `instagram_posten.py` aus dem Repo
`ronperduss/verbraucherexperte`.
